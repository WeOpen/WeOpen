## PROJECT NULLFRAME

- Project: PROJECT NULLFRAME (`nothing-sys-v4`)
- Author: Mick Cesanek
- Source: https://github.com/m1ckc3s/nullframe
- License: MIT

The WeOpen design system's **Telemetry** section ports and adapts PROJECT
NULLFRAME's bento telemetry board, including its card set, command palette,
motion timing, simulated/live telemetry bus, canvas glyph, network, and input
visualizations. The code has been adapted into WeOpen's Next.js design-system
surface and namespaced styling.
